# 파인튜닝 학습 데이터 — 도메인 예시 (발췌)

> **출처**: AI Hub 전화망 상담음성(KtelSpeech) / manifest `train_16k.jsonl`
> **학습 사용분**: 16,000건(~20GB), 전체 ~1000시간 규모에서 추출
> **발췌 방법**: seed=42 고정 무작위 추출 (재현 가능)
> **주의**: 아래 발화의 이름·수치는 공개 데이터셋의 가명 처리된 대본이며 실제 개인정보가 아님

## 금융/보험 상담 도메인 어휘 (해당 유형 277건 / 16,000건 중 발췌)

- `콜센터를 통해서 가입하게 되면, 약관이나 상품설명서는 집으로 배송해 주시나요? 아니면 이메일이나 문자로 보내주시나요?`
- `건강보험 자격득실 확인서요. 이거 건강보험공단 홈페이지에서 발급받을 발급할 수 있는 거 맞죠?`
- `에이보험은 오프로 비보험은 육프로입니다.`

두 번째 샘플의 "발급받을 발급할" 같은 반복이 그대로 살아 있는 것이
이 데이터셋의 핵심 가치다 — 정제·재작성된 전사가 아니라 발화 그대로의
전사(D-8 판별 기준 2). 세 번째의 "오프로/육프로"(5%/6%)는 전화망 구어의
숫자 발화 표기 예.

## 이중 표기·간투사 원문 규칙 (manifest 전처리본에서는 미검출 — 정직 표기)

`train_16k.jsonl`은 학습용 전처리를 거친 전사라 원본 데이터셋의
`(mobile)/(모바일)` 이중 표기, `그/` 간투사 마킹은 이미 풀린 상태로
확인됨(정규식 검출 0건). 해당 규칙의 존재 근거는 DECISIONS.md D-8
(데이터셋 판별 당시 원본 확인 기록) 참조.

## 모델이 실제로 뭘 배웠는가 → `exp_samples/` 참조

학습 데이터보다 학습 **결과**가 도메인 적합성을 잘 보여준다:

- 숫자 낭독 학습: `exp_samples/exp8_...json` improved —
  "김창추리구요... 7 5 0 2" → "김 창출이구요... 칠 오 공 이" (CER 40.0→6.7)
- 날짜 표기: "80년 2월 2일" → "팔십 년 이 월 이 일" (46.7→0.0)
